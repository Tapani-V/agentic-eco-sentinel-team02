KEY ARCHITECTURE FEATURES
================================================================================

1. Cost Optimization: Router skips DiagnosisAgent for healthy devices
   - Happy: 80ms, $0, no LLM
   - Simple: 200ms, $0.0001, no LLM (confidence ≥0.85)
   - Ambiguous: 450ms, $0.01, LLM used (confidence <0.85)
   - Critical: 120ms, $0.0001, no LLM

2. Hybrid AI Approach: Rules + LLM
   - Rules for deterministic cases (fast & cheap)
   - LLM for ambiguous cases (accurate)
   - Confidence threshold: 0.85

3. MCP Tool Integration: 3 AWS Tools
   - get-spare-parts (S3 inventory)
   - schedule-maintenance (DynamoDB)
   - create-work-order (App Runner)

4. Core + Wrapper Pattern: Reusable components
   - Core logic: Pure Python classes
   - HTTP wrappers: FastAPI services
   - Containerized: Docker deployment
